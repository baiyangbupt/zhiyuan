# 初始方案评估矩阵

## 1. 文档目的

本文档用于固定“初始方案生成”与“老版本优选推荐”对照测试的统一样本口径，避免后续评估时：

- 每轮选样本标准不一致
- 对“合理性”的判断标准不一致
- 新旧版本差异无法归因

当前评估重点是：

- 新版初始方案在前置更多审查规则后，是否仍能给出合理方案
- 新版相对老版“单纯推荐优选”的结果变化是否符合预期
- 这些变化能否用用户信息、供给结构和规则修正解释清楚

## 2. 评估对象

每个测试样本都要同时输出两套结果：

### A. 老版本结果

指当前推荐链路中“按候选过滤 + rank 打分 + 九宫格合并 + 专家优选标记”的结果。

关注项：

- `three_target_count_map`
- `preferred` 标记结果
- 冲稳保内的优选分布

### B. 新版本结果

指 `sessionDetailV2` 当前使用的 planning 编排链路。

关注项：

- `candidatePoolState.requiredTierCounts`
- `initialRecommendationState`
- `draftPlanState`
- `orderedPlanState`
- 命中的结构修正规则

## 3. 样本维度

每个样本必须同时记录以下 8 个维度。

### 3.1 省份

用于覆盖：

- `major` 模式
- `majorGroup` 模式
- 不同省份下候选供给和录取率结构差异

建议按模式优先选省：

- `majorGroup`：河南、河北、辽宁
- `major`：山东、广东、四川

### 3.2 总分

记录用户输入的原始成绩。

说明：

- 用于描述用户的绝对分数
- 不单独作为低中高分层的唯一依据

### 3.3 选科

用于刻画候选池供给差异。

第一批建议覆盖常见组合：

- 物化生
- 物化政
- 史政地
- 史政生

### 3.4 成绩相对位置

这里统一定义为“位次 / 批次线相对位置”，用于替代模糊的“高分、中分、低分”。

每个样本需至少记录：

- 位次
- 当前批次
- 与批次线的分差

并按以下更细的口径分档：

- `L1`：贴线段
  与批次线差值 `0 - 15`
- `L2`：低分段
  与批次线差值 `16 - 40`
- `M1`：中低段
  与批次线差值 `41 - 80`
- `M2`：中高段
  与批次线差值 `81 - 140`
- `H1`：高分段
  与批次线差值 `141 - 220`
- `H2`：高位段 / 头部段
  与批次线差值 `220+`

说明：

- 对不同省份不要机械只看绝对分差，仍需结合位次判断
- 若某省批次线和整体分布特殊，允许用“同省位次百分位”对上述档位做人工校正
- 后续汇总时仍可再聚合回 `低 / 中 / 高` 三大类，但抽样和分析阶段按 `L1/L2/M1/M2/H1/H2` 执行

### 3.5 性别

当前统一为：

- 男
- 女

目的：

- 验证性别相关限报和专业建议是否产生异常偏置

### 3.6 专业意向

建议分为以下四类：

- 强理工意向
- 强文社科意向
- 泛专业意向
- 带明确排除专业

记录时既要保留原始专业列表，也要归类到上述标签。

### 3.7 地域意向

建议分为以下四类：

- 无明显地域意向
- 偏好发达地区
- 偏好本省或周边
- 明确排除某省或某区域

记录时需要同时保留：

- 正向地域偏好
- 负向地域约束

### 3.8 填报策略

当前统一使用：

- 保守
- 稳妥
- 激进

目的：

- 验证目标冲稳保数量和最终方案结果是否一致
- 验证无保区供给时的借位逻辑是否合理

## 4. 组合抽样原则

不采用全排列，而采用“基础层 + 画像层”的分层组合抽样。

### 4.1 基础层

由以下四项组成：

- 省份
- 选科
- 成绩相对位置
- 填报策略

这一层决定“候选供给空间”。

### 4.2 画像层

由以下三项组成：

- 性别
- 专业意向
- 地域意向

这一层决定“推荐偏向和方案解释”。

### 4.3 每省抽样模板

建议每个省先固定 8 个基础样本：

1. `L1` + 主流选科 + 保守
2. `L2` + 次主流选科 + 稳妥
3. `M1` + 主流选科 + 保守
4. `M1` + 主流选科 + 激进
5. `M2` + 主流选科 + 稳妥
6. `H1` + 主流选科 + 保守
7. `H1` + 次主流选科 + 激进
8. `H2` + 主流选科 + 稳妥或激进

每个基础样本再挂 2 个画像变体：

- 变体 A：男 + 强理工意向 + 强地域意向
- 变体 B：女 + 泛专业或稳定型专业意向 + 弱地域意向或负向地域约束

则每省首轮样本数为：

- `8 x 2 = 16`

## 5. 第一批测试范围建议

第一批建议先覆盖 4 个省：

- 河南
- 山东
- 广东
- 河北

则总样本量为：

- `4 x 16 = 64`

这批样本能够先覆盖：

- `major` 与 `majorGroup`
- 不同分数段
- 不同选科
- 不同策略型
- 不同性别和主流画像差异

## 6. 样本记录模板

每个样本建议统一记录以下字段。

### 6.1 输入信息

- `sampleId`
- `sessionId` 或画像来源
- `province`
- `volunteerModel`
- `totalScore`
- `rank`
- `batch`
- `scoreGapToBatch`
- `subjectCombination`
- `gender`
- `strategyType`
- `positiveMajorIntent`
- `negativeMajorIntent`
- `positiveRegionIntent`
- `negativeRegionIntent`

### 6.2 老版本结果

- `legacyTargetTierCounts`
- `legacyReturnedTierCounts`
- `legacyPreferredTierCounts`
- `legacyRepresentativeItems`

### 6.3 新版本结果

- `v2RequiredTierCounts`
- `v2CandidatePoolTierCounts`
- `v2InitialTierCounts`
- `v2DraftTierCounts`
- `v2OrderedTierCounts`
- `v2SummaryTotal`
- `v2RepresentativeItems`
- `v2UnresolvedRuleCodes`

### 6.4 差异分析

- `differenceSummary`
- `safetyDelta`
- `intentAlignmentDelta`
- `structureDelta`
- `suspectedReason`

### 6.5 结论标签

统一使用以下枚举：

- `better_than_legacy`
- `roughly_equal`
- `safer_but_more_conservative`
- `more_intent_aligned_but_riskier`
- `possible_regression`

## 7. 合理性判断标准

每个样本都要从以下四类维度判断结果是否合理。

### 7.1 结构合理

- 总数满足目标数，或能解释为什么不足
- 冲稳保分布尽量贴近目标
- 无保区供给时优先向稳借位，而不是继续堆冲
- `majorGroup` 下按组统计正确，不按专业条目虚高

### 7.2 审查合理

- 梯度断层减少
- 概率倒挂减少
- 本省保底在适用场景下更稳定
- 组内专业数量满足要求
- 组内优先保留安全垫专业

### 7.3 用户合理

- 硬约束不被违反
- 软意向在推荐中有体现
- 学费、中外合作、限报等敏感项不会异常冲到前排

### 7.4 对照合理

- 新版更安全且推荐质量没有明显退化
- 新版更贴合画像且结构更稳
- 新版虽然过审更强，但过于保守时应标记为待优化
- 老版明显更自然而新版机械时，应标记为疑似退化

## 8. 执行步骤

建议按三轮执行。

### 8.1 第一轮：真实会话盘点

目标：

- 从本地数据库中查找已有会话
- 映射到上述 8 个维度
- 看当前真实数据能覆盖哪些样本格子

### 8.2 第二轮：定向补样

目标：

- 对缺失省份、缺失分数段、缺失选科或缺失画像做人工补样
- 补到首轮测试矩阵足够代表性

### 8.3 第三轮：新旧对照分析

目标：

- 统一输出每个样本的新旧差异
- 给出按省份、模式、分数段的汇总结论
- 标记后续需要单独优化的异常样本

## 9. 最终产出

最终建议形成三份结果物：

### A. 样本明细表

一行一个样本，记录输入、老版结果、新版结果和结论标签。

### B. 汇总表

按以下口径聚合：

- 省份
- 模式
- 分数段
- 策略型

### C. 问题清单

把异常样本拆成三类：

- 算法问题
- 供给问题
- 样本本身特殊性

## 10. 真实样本不足时的补样规则

当前本地真实会话样本不足以覆盖全部矩阵时，允许人工补样，但必须遵守以下原则。

### 10.1 优先补哪些缺口

优先级按以下顺序：

1. 省份缺口
2. 高分段缺口，尤其 `H1 / H2`
3. 选科缺口
4. 性别对照缺口
5. 策略型横向缺口
6. 强意向 / 强约束缺口

### 10.2 补样方式

人工补样时优先复用真实省份口径，再替换部分字段形成测试画像：

- 省份和批次线按目标省份真实规则填写
- 总分和位次按目标分段填写
- 选科按该省常见组合填写
- 性别、专业意向、地域意向、策略型按测试目标填写

### 10.3 高分补样要求

由于当前本地真实样本高分段明显不足，后续补样必须显式补入：

- 每个测试省至少 1 个 `H1`
- 每个测试省至少 1 个 `H2`
- `H2` 样本优先覆盖：
  - 强专业意向
  - 强地域意向
  - 激进 / 稳妥策略对照

### 10.4 补样结论口径

人工补样与真实样本在最终报告中要区分标记：

- `real_session`
- `synthetic_profile`

避免后续把人工补样误认为线上真实用户分布。
