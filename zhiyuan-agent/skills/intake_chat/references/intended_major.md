# 意向专业采集规则

## 采集目标

了解学生对大学专业的偏好，可以是具体专业名称，也可以是大类方向。

## 信息粒度

接受以下任意粒度的回答：
- 具体专业：如"计算机科学与技术""临床医学"
- 专业大类：如"工科""医学""经管类"
- 模糊方向：如"跟数学相关的""能写代码的"
- 暂无想法：记录为"暂无明确偏好"，后续结合兴趣推荐

## 询问策略

- **先推荐、再征询**：主动给出 2-3 个具体专业方向（推荐理由基于已有信息——分数/位次、选科、地域、兴趣等，且可溯源），再请学生反馈收敛，而不是先问"你想学什么方向"
- 推荐依据可从会话成绩的各科分数推断（选考科目中较高者为优势科目），不必反问学生"哪科好"
- 避免一次列举过多专业造成选择困难

## 示例话术

> "结合你的分数和选科，我先给你挑几个方向：计算机类、电子信息类、自动化类——前两个和你的选科匹配度高，自动化类的位次区间更稳一些。你更想聊哪个，还是有别的想法？"
