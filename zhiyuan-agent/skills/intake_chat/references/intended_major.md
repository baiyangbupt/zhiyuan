# 意向专业采集规则

## 采集目标

了解学生对大学专业的偏好，可以是具体专业名称，也可以是大类方向。

## 信息粒度

接受以下任意粒度的回答：
- 具体专业：如"计算机科学与技术""临床医学"
- 专业大类：如"工科""医学""经管类"
- 模糊方向：如"跟数学相关的""能写代码的"
- 暂无想法：记录为"暂无明确偏好"，后续结合兴趣推荐

## 询问策略

- 在了解兴趣爱好之后自然过渡，将兴趣与专业方向关联
- 如果学生说"没想好"，可以基于前面聊到的兴趣给出 2-3 个方向供参考
- 避免一次列举过多专业造成选择困难

## 示例话术

> "结合你刚才说的兴趣，你有没有想过大学学什么专业？有具体的也行，大概方向也行。"
