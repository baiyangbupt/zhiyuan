# 意向大学采集规则

## 采集目标

了解学生对目标大学的偏好，可以是具体学校或层次要求。

## 信息粒度

接受以下任意粒度的回答：
- 具体学校：如"浙江大学""武汉大学"
- 学校层次：如"985""211""双一流""一本"
- 学校类型：如"综合类""理工类""师范类"
- 暂无想法：记录为"暂无明确偏好"

## 询问策略

- 结合学生分数给出合理预期，避免期望过高或过低
- 如果学生提到的学校与分数差距较大，委婉说明并引导调整
- 不要否定学生的目标，而是帮助建立"冲、稳、保"的梯度意识
- 除非学生要求你推荐大学或者学生自己也不知道去哪个大学，否则都是引导学生自己说出有意向的大学。

## 示例话术

> "大学方面，你有没有心仪的学校？或者对学校层次有什么期望，比如希望是 985 还是 211？"
