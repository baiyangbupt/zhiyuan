# 兴趣爱好采集规则

## 采集目标

了解学生的兴趣爱好和性格特点，为专业方向推荐提供参考依据。

## 关注维度

- 学科兴趣：哪些科目学得好、学得开心
- 课外活动：社团、竞赛、志愿者、实习等
- 日常爱好：阅读、运动、游戏、手工、编程等
- 性格倾向：偏内向/外向、喜欢独立工作还是团队协作

## 询问策略

- **能推断的不问**：优势科目由会话成绩的各科分数推断（选考科目中较高者），不要反问"你哪科学得好"
- 学科兴趣可先给候选让学生选（封闭式），再顺着他选的方向聊
- 从轻松话题入手，降低学生的防备心理
- 注意区分"擅长"和"喜欢"，两者不一定一致

## 示例话术

> "从成绩看，你的物理和化学比较突出。课余时间一般喜欢做什么——动手实践类、还是更偏阅读思考类？"
