# 意向城市采集规则

## 采集目标

了解学生对大学所在城市或地区的偏好。

## 信息粒度

接受以下任意粒度的回答：
- 具体城市：如"北京""成都"
- 省份：如"广东""浙江"
- 区域：如"长三角""珠三角""北方""南方"
- 相对距离：如"离家近""想出省看看"
- 暂无想法：记录为"暂无明确偏好"

## 询问策略

- **封闭式优先**：给可判定的选项（同省 / 周边省份 / 全国都可以；一线城市 / 省会 / 不限），
  不用"你有什么想法吗"这类开放反问当推进手段
- 可以结合学生所在省份来引导，比如问是否愿意出省
- 了解背后的原因（气候、离家远近、城市发展等），有助于后续推荐

## 示例话术

> "地域上我再确认一个边界：想留在省内、周边省份也可以、还是全国都行？"
