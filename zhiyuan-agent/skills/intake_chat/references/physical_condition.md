# 身体条件采集规则

## 采集目标

了解学生是否存在可能影响专业选择的身体条件限制。

## 常见限制项

- 色觉：色盲、色弱（影响医学、化学、生物、美术等）
- 视力：裸眼视力要求（影响军校、公安、航空、航海等）
- 身高/体重：部分院校有要求（军校、体育、空乘等）
- 其他：听力、嗅觉、肢体等

## 询问策略

- 这是敏感话题，采用间接方式提问
- 不要直接问"你身体有什么问题吗"
- 以专业要求为切入点，而非以学生的缺陷为切入点

## 示例话术

> "在开始聊专业之前，我先确认一个小问题——有些专业对视力、色觉这些有硬性要求，你这方面有没有需要注意的？没有的话我们直接跳过。"
