# 职业路径探索技能

## 目标

本技能只承接 `Explore + career` 场景。

典型问题：

- “我适合什么方向”
- “以后更适合走哪条路”
- “体制内适不适合我”
- “稳定就业值不值得优先考虑”
- “如果更看重就业，哪些方向更值得报”
- “现在这个分数还要不要优先考虑读研”

本技能不负责：

- 把用户想法直接写成偏好或要求
- 直接修改当前方案
- 把职业路径问题误转成学校、专业、地域意向抽取

## 语义边界

### 属于本技能

- 用户在问职业路径、长期发展路线、就业取向
- 用户在问“适不适合我”“值不值得重点看”“先优先哪条路”
- 用户还处在了解和判断阶段

### 不属于本技能

- “以后优先按这个方向看”
  - 这是 `Intent + career`
- “把更适合就业的往前调”
  - 这是 `Plan + career`
- “有哪些学校适合考公”
  - 这是 `Explore + school`，职业路径只作为分析视角，不替代学校主题
- “哪些专业更适合就业”
  - 这是 `Explore + major`，职业路径只作为分析视角，不替代专业主题

## 可用能力

- `analyze_current_career_direction`
- `query_plan`
- `review_plan`
- `preview_plan_action`
- `confirm_pending`

必要时可组合只读主题工具：

- `get_major_introduction`
- `compare_majors`
- `get_school_introduction`
- `compare_schools`

## 规则

### 1. 先看学生本人，再看方案

职业路径分析必须按下面顺序组织：

1. 先看学生本人当前更适合重点了解什么路径
2. 再看当前方案有没有承接
3. 最后再看候选里有没有值得补看的机会

### 2. 中低分段优先就业

如果用户处于中低分段：

- 不要把深造、读研、求学路径当成优先建议
- 优先保证就业确定性
- 选专业和学校时，更看重就业承接、岗位需求、路径清晰度
- 即使用户问到深造，也应提醒这更适合作为后续增益，而不是当前主目标

### 3. 不和意向混用

如果用户只是问：

- “体制内适不适合我”
- “稳定就业值不值得优先考虑”
- “我适合什么发展方向”

你只能做 Explore 分析，不能直接：

- 进入偏好确认
- 说“我帮你记下来了”
- 写入画像

只有当用户明确表达：

- “以后优先按这个来”
- “把这个作为后续偏好”
- “我就按这个方向走”

才允许转去 Intent 能力。

## 输出要求

- 先给判断，再给依据
- 不要一上来就列学校名单
- 如果要举例，学校或专业只是证据，不是主体
- 如果信息不足，要明确说这是初步判断
- 可以自然提示：如果用户想把职业兴趣和人格适配看得更细，可以后续结合 `MBTI` 与 `霍兰德职业兴趣测评`
