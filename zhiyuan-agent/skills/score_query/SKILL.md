# 录取分数查询技能

## 目标
本技能用于处理用户对**录取分数和分数线**的查询需求，包括：
- 查询某学校对于当前学生分数（或用户指定分数）的录取可能性（冲/稳/保级别）
- 查询某学校或某专业的历年录取分数线
- 了解学校录取分、位次、录取人数等信息

典型场景：
- "我这个分数能上北京大学吗"
- "550分湖南物化生能不能上长沙理工"
- "帮我查下河北600分理科能上哪些学校"
- "清华大学的录取分数线是多少"
- "北京大学计算机专业历年分数线"
- "武汉大学去年最低多少分"
- "北京大学在湖南的分数线"

## 可用工具

### query_admission_score
- **用途**：查询某学校在指定分数下是否能够录取（冲/稳/保级别）
- **参数**：
  - `school_name`（学校名称，必填）
  - `score`（查询分数，可选）：用户明确提到了分数时传入，如"550分能上XX吗"传 550；不传或传 0 则使用当前学生自己的分数
  - `province`（省份名称，可选）：用户明确提到了省份时传入，如"湖南550分"传"湖南"；不传则使用当前学生自己的省份
  - `subjects`（选科，可选）：用户明确提到了选科时传入，如"物化生"传"物化生"、"理科"传"理科"；不传则使用当前学生自己的选科
- **使用场景**：
  - 用户问自己的分数能否上某校："我能上清华吗"
  - 用户用指定的分数/省份/选科查询："550分湖南物化生能不能上长沙理工"
  - 用户帮别人查询："河北600分理科能上北京大学吗"
- **返回**：学校在该分数段下的录取级别、录取分数、位次、近年招生专业等信息

### query_score_line
- **用途**：查询某学校（及可选专业）的历年录取分数线
- **参数**：
  - `school_name`（学校名称，必填）
  - `major_name`（专业名称，可选）：不传则查学校整体分数线
  - `province`（省份名称，可选）：用户指定省份时传入，不传则使用当前学生自己的省份
  - `subjects`（选科，可选）：用户指定选科时传入，不传则使用当前学生自己的选科
- **使用场景**：用户想了解某学校或某专业的历年录取分数线
- **返回**：历年录取分数线数据（最低分、最高分、平均分、位次等），并与当前分数进行对比

## 参数提取指引

当用户的查询中包含分数/省份/选科信息时，需要正确提取并传入对应参数：

| 用户说的话 | score | province | subjects |
|---|---|---|---|
| "我能上清华吗" | 0（用自己的） | ""（用自己的） | ""（用自己的） |
| "550分能上北大吗" | 550 | ""（用自己的） | ""（用自己的） |
| "湖南550分物化生能上长沙理工吗" | 550 | "湖南" | "物化生" |
| "河北理科600分上北大" | 600 | "河北" | "理科" |
| "北大在湖南的分数线" | — | "湖南" | — |

**选科常见简写**：物化生=物理+化学+生物，物化政=物理+化学+政治，史地政=历史+地理+政治 等。工具内部会自动展开简写。

## 工具选择指引

- 用户问"我能上XX学校吗"、"XX分能上XX吗"、"XX学校对我来说是冲还是稳" → 使用 `query_admission_score`
- 用户问"XX学校分数线多少"、"XX学校XX专业录取分"、"XX学校在XX省的分数线" → 使用 `query_score_line`
- 如果用户同时想知道录取可能性和分数线，可以先用 `query_admission_score` 查录取级别，再用 `query_score_line` 补充分数线细节

## 前提条件
- 查询需要省份和分数信息。如果当前学生有成绩信息，未指定参数时会自动使用学生的成绩
- 如果学生没有成绩信息，且用户也没有在对话中指定分数/省份，则引导用户提供这些信息

## 输出风格
- 使用专业高考志愿规划师的口吻
- 清晰展示录取级别和分数对比
- 给出合理的建议（如分数不够时建议关注分数线较低的相关院校）
- 数据不足时坦诚说明并给出替代建议
