# Changelog

## Unreleased

### Fixed

- `sessionDetailV2` 桌面端双栏布局调整为对话约 43%、工作面板约 57%，兼顾对话阅读和方案操作空间。
- `sessionDetailV2` 方案卡片补充展示候选侧已有的院校排名标签，辅助解释院校层次排序结果。
- `sessionDetailV2` 方案卡片刷新后展示录取率、推荐系数和院校排名标签的稳定性依赖后端工作区轻量状态补齐历史方案候选详情，不再依赖候选分页加载顺序碰巧命中。
- `sessionDetailV2` 候选页排序入口恢复为候选浏览维度，保留推荐系数、录取率、院校层次、区间位次、专业热度、薪酬指数和学费，避免方案排序收口误伤候选排序。

- `sessionDetailV2` 方案和候选工作区增加滚动后的“回到顶部”浮动按钮，候选页按钮避开底部方案篮，提升长列表调整效率。
- `sessionDetailV2` 页头会话列表入口强化为带返回图标的“返回会话列表”主按钮，提升 B 端用户从详情页回到列表页的可发现性。
- `sessionDetailV2` 候选概览恢复展示冲/稳/保数量分布，候选生成状态改回在列表空态或 tooltip 中提示，避免顶部概览信息过泛。

- `sessionDetailV2` 工作台顶部概览收口为短状态标签，候选为空原因在空态中展示，候选偏少原因通过 tooltip 展示，审查详情继续收敛在方案区警示 tooltip。
- `sessionDetailV2` 工作台顶部概览去掉重复方案卡，仅保留候选、方案、审查三项；方案概览统一展示已有方案数/目标方案数和冲稳保分布，审查风险/提醒状态补充“请查看方案”引导。
- `sessionDetailV2` 审查状态文案将“需复审”调整为“待重新审查”，方案区审查按钮固定为“审查”且不再使用惊叹号图标；候选页浮动方案篮改为橙色主题，并用当前排序/已选方案数量兜底，避免切到候选时显示 0。
- `sessionDetailV2` 候选篮子用户侧文案从“草稿”收口为“方案 / 当前方案”，锁定、删除、空态等提示同步改为方案语义。
- `sessionDetailV2` 方案区新增显式“审查 / 复审”按钮，直接触发现有审查接口并刷新工作台状态。
- `sessionDetailV2` 候选排序入口收口为推荐系数、录取率、院校层次三项，减少无优先级字段带来的选择噪音。
- `sessionDetailV2` 候选区浮动方案篮改为蓝色系，与候选条目里的冲稳保红橙绿标签区分。
- Web Dockerfile 基础镜像切换为公开 `node:22.14.0`，避免 release 构建时访问 `docker.m.daocloud.io` 返回 401 导致 amd64 镜像无法构建。
- 根目录 Docker Compose 为 `zhiyuan-web / zhiyuan-agent / zhiyuan-rank` 增加容器 healthcheck，发布后可通过 `docker compose ps` 直接观察健康状态；web 探活使用容器内 Next.js 端口 `28688`。
- `sessionDetailV2` 工作台移动端隐藏顶部“候选 / 草稿 / 方案 / 审查”统计概览，首屏直接展示“方案 / 候选”切换和列表主体，减少小屏空间占用。
- `sessionDetailV2` 候选区加入按钮文案从“加入草稿 / 已加入草稿”调整为“加入方案 / 已加入方案”，与用户实际看到的方案列表语义保持一致。
- `sessionDetailV2` 工作区移动端学校/专业组标题栏去掉学校名前重复的冲稳保标识，学校名与优选、锁定、状态标签放在同一标题区，右侧录取概率列统一展示概率和梯度，避免长标题与标签错位。
- `/sessionDetailLegacy` 移动端快捷入口收敛为老版外壳中的 `志愿方案 / 会话列表`，历史会话中常驻展示；`会话列表` 改为抽屉并支持在抽屉内创建智能方案，避免跳转到旧列表页后新建报错。
- `/sessionDetailV2` 移动端不再展示初始化提问式快捷回复，改为常驻 `志愿方案 / 会话列表` 两个导航型入口；`志愿方案` 由新工作区抽屉承载并定位到当前方案。
- `/sessionDetailLegacy` 和 `/sessionDetailV2` 的移动端外壳向老版 `gaotu-mobile-v2.0.6` 对齐：默认保留对话主视图，通过快捷入口或对话联动以全屏抽屉打开旧版志愿表 / V2 工作台，避免移动端继续按 PC 双区 tab 平铺。
- `sessionDetailV2` 工作台刷新改为调用轻量 `workspace-state`，不再通过完整 `/session/state` 拉取 20MB+ 规划状态；候选列表继续通过分页 `candidate-pool/query` 获取当前页，降低公网刷新等待和浏览器 JSON 解析成本。
- `sessionDetailV2` 方案区刷新后会把 `workspace-state` 返回的当前方案候选明细写入本地候选缓存，避免山西大同大学、燕京理工学院等未命中候选分页缓存的方案项丢失录取率、推荐系数、专业热度和薪酬指数。
- `sessionDetailV2` 首次自动生成方案、刷新候选池、草稿增删锁定等返回规划状态的路径统一合并候选明细缓存，避免新建会话刚出方案时必须手动刷新后才显示录取率、推荐系数、专业热度等指标。
- `sessionDetailV2` 对话工作台卡片收口为当前实际支持的 `candidate / ordered` 两类视图；历史或异常返回的 `review / draft` 卡片不再渲染，避免出现“审查结果”等无对应工作区入口的误导卡片。
- `sessionDetailV2` 方案区上移、下移、固定、取消固定操作改为消费后端轻量响应并合并本地排序态，同时补充操作 loading，避免每次调整后重新拉取 20MB+ 全量 `planningState` 导致长时间无提示等待。
- `sessionDetailV2` 工作台移动端候选专业明细改为纵向信息卡展示，并收紧概览、筛选、方案卡片和草稿篮的小屏换行规则，避免横向表格和长文本撑破屏幕。

### Added

- 新增 `/sessionDetailLegacy` 迁移兜底页面，复用老版志愿表展示和旧推荐/导出接口，支持迁移期只读回看老方案，并提供返回 V2 工作台入口。
- 新增 `zhiyuan.ytell.cn` 部署记录文档，覆盖旧版服务清理、新版 backend/web/agent/rank 部署、Nginx SSL、DNS 切换、运行验证与后续 TODO。
- `sessionDetailV2` 对话框首屏新增轻量通用快捷提问入口，仅在会话初始消息较少时展示；问题改为不预设具体地域/专业偏好，只提供“看看现在方案 / 我适合什么方向 / 有哪些机会可看 / 方案哪里要注意”这类通用起手问法。
- `sessionDetailV2` 候选筛选面板补齐专业门类 / 专业大类分层映射字典，并支持按院校地域树、专业层级树做搜索与正负筛选；草稿区在专业组模式下同步改为按组聚合展示并支持整组删除。
- `MessageList` 新增拉取队列与结构化意向分析卡片处理能力，兼容兴趣分析按钮、确认卡片点击置灰与结构化回执过滤，降低 WebSocket / 轮询并发下的重复刷新与回显噪音。
- 新增建会话超时兜底文档，记录 `sessionDetailV2` 切主入口后创建失败的真实根因、超时止血策略与前端回查会话方案。
- 新增切页前标签治理与协议统一文档引用，明确 `sessionDetail -> sessionDetailV2` 正式切换前必须完成 frontend / backend / agent 的候选筛选字段对齐。
- 新增对话富内容输出与展示美化方案文档，统一规划 agent 输出约束、markdown 渲染层、结构化卡片协议与渐进式改造顺序，作为后续修复表格错位、列表缩进和风险/对比消息美化的设计基线。
- 新增 `sessionDetailV2` 移动端展示修复设计文档，记录候选专业纵向卡片、小屏换行和验证方式。
- 新增 `sessionDetail` legacy 兜底入口设计文档，明确老版会话详情页不恢复为主链路，仅作为灰度期只读回看和迁移失败兜底。
- 新增 `sessionDetailLegacy` 验证清单，覆盖桌面、移动端、导出、旧方案空态和不写 `planningState` 等迁移兜底口径。
- `sessionDetailV2` 新增候选视图状态持久化接线，工作台筛选与排序方式可回写 `planningState.candidateViewState`。
- `sessionDetailV2` 候选志愿卡片切换为消费 planning 候选池的真实结构化字段，补齐院校排名、保研率、硕博点、专业代码、学制、计划数、历史分数等展示所需的数据类型。
- `sessionDetailV2` 候选筛选新增 `院校排名` 排序字段，排序能力与 backend comparator 对齐。
- 会话详情页新增 `sessionDetailV2` 双栏工作台页面，左侧复用真实对话链路，右侧接入轻量 planning workspace。
- `sessionDetailV2` 工作台新增候选志愿 / 排序方案双视图，以及浮动草稿篮快捷入口。
- `sessionDetailV2` 工作台接入真实 planning 接口，支持刷新候选池、加入草稿、移出草稿、锁定草稿、生成排序、上下移动、固定位置和执行审查。
- `sessionDetailV2` 排序区顶部新增轻量审查标签与 tips 展示，并透出补偿建议数量提示。
- 旧版会话详情页头部新增 `工作台 V2` 入口，可保留当前会话参数直接跳转到并行验证页。
- planning 前端类型补充后端真实字段映射，包括 `candidatePoolState.items`、`draftPlanState.bannedVolunteerIds`、`reviewState.compensationPreview`、`profileState`、`constraintState` 与 `operationLogs`。
- 会话消息渲染改为兼容当前 `marked` 版本的实例化写法，避免旧页与 V2 复用 `MessageList` 时出现类型与渲染不一致问题。

- `sessionDetailV2` 工作台主 tab 改为横向铺满的双按钮样式，替代紧凑分段控件。
- `sessionDetailV2` 候选筛选区改为常驻展开的冲稳保切换、标签追加输入、漏斗排序字段选择和升降序箭头切换，并改为自动生效。
- `sessionDetailV2` 候选志愿卡片补充专业主副标题展示、志愿模型标识、推荐系数、专业热度和薪酬指数等信息。

- 修复 `sessionDetailV2` 页面对 `Spin` 容器高度未拉满导致双栏只占上半屏的问题，并将候选区折叠面板改为显式 `Panel` 写法以降低当前环境下的前台渲染报错风险。
- `sessionDetailV2` 候选区取消按冲稳保分栏展示，改为单列表院校折叠；冲稳保仅作为专业名前标签保留，院校右侧数字调整为录取率，并移除无用的“院校专业组”类型标签。

- `sessionDetailV2` 恢复前端采集入口下的“首次进入自动出方案”链路：若当前会话尚无草稿和方案，页面首次进入时会异步触发 `generateInitialPlan`，直接生成一份可编辑的初始方案并默认落到“方案”视图。

- 志愿详情页顶部新增统一规划状态摘要卡片，展示阶段、草稿数、排序数、风险提醒与待处理建议。
- 志愿详情页新增 planning workspace 只读骨架，可切换查看草稿、排序与审查摘要。
- 志愿详情页新增 planning 轻量操作入口，支持刷新状态、执行审查与预览补偿。
- 志愿详情页补偿预览弹层新增一键应用入口，可在确认后直接执行补偿并同步刷新草稿、排序和审查状态。

- 志愿详情页排序区新增轻量编辑入口，支持重新生成排序、固定与取消固定。
- 志愿详情页排序区新增轻量位置调整入口，支持单项上移与下移。

- 会话详情页新增对话到 planning workspace 的轻量联动能力，消息卡片可直接切换到草稿、排序、审查视图并触发对应刷新与聚焦。

- `sessionDetailV2` 候选区专业卡片与方案区组内专业行补齐“专业热度 / 薪酬指数 / 学费”展示，且推荐系数、录取率及其他浮点指标统一收口为最多 1 位小数，降低数字噪音。
