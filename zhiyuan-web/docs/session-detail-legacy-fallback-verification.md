# sessionDetailLegacy 验证清单

## 访问方式

```text
/sessionDetailLegacy?chatSessionId={chatSessionId}&userId={userId}
```

页面用途是迁移期查看老版志愿方案，不替代 V2 主工作台。

## 功能验证

1. 使用有老方案文件的历史会话进入页面。
2. 确认顶部展示 `旧版志愿方案`、`Legacy` 标识、会话状态和基础摘要。
3. 桌面端确认左侧对话、右侧志愿表同时展示。
4. 移动端确认默认进入对话主视图。
5. 移动端历史会话也要常驻底部快捷入口，不因已有用户消息而隐藏；入口只展示 `志愿方案` 和 `会话列表`。
6. 移动端点击快捷入口 `志愿方案` 后，旧版志愿表以全屏抽屉打开。
7. 移动端点击快捷入口 `会话列表` 后，会话列表以全屏抽屉打开，不跳出 legacy 会话详情页。
8. 在会话列表抽屉中点击已有会话，进入同一个 `/sessionDetailLegacy` 兜底页面并切换 `chatSessionId`。
9. 在会话列表抽屉中点击 `创建智能方案`，权益通过后打开移动端创建流程抽屉；创建成功后跳回 `/sessionDetailLegacy`。
10. 志愿表能加载冲、稳、保三类数据。
11. 院校/专业组折叠、优报/候补折叠可用。
12. 历年录取分数线弹层可打开和关闭。
13. 导出按钮可触发旧版导出接口。
14. 页面没有提交按钮，没有学费滑块重算入口。
15. 点击 `返回 V2 工作台` 能回到同一个 `chatSessionId` 的 `/sessionDetailV2`。

## 移动端验证

使用 375px 或 390px 宽度验证：

- 冲稳保 tab 三等分展示，不挤出屏幕。
- 院校标题、标签和右侧录取率块能换行或压缩展示。
- 专业明细表格可横向滚动。
- 页面底部回顶部按钮可用。
- 关闭志愿方案抽屉后回到对话主视图。
- 关闭会话列表或创建流程抽屉后回到对话主视图，底部快捷入口仍可点击。
- 不展示老版 `用户信息` 入口，也不展示 V2 的提问式快捷回复。

## 边界验证

- 老方案为空：展示空态，不阻断页面。
- 推荐接口失败：页面提示获取志愿列表失败。
- 对话权限不足：对话区沿用现有 MessageList 权益提示。
- `planningState` 不应因为访问 legacy 页面被创建或修改。
