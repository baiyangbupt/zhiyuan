| 边界 | 本轮要求 |
|---|---|
| 对话确认 | 取消、确认处理或更新的预览结果构成历史候选屏障，不能复活更老的只读预览；有效新预览仍可确认 |

| 当前事实 | 当前专业组使用实际已选专业计算 coverage、偏好与内容风险基线，不以整组候选或重新预选替代事实 |
| 两阶段一致 | 阶段二复用阶段一的专业计划，`requiredMajorCount` 贯穿补足 policy，legacy 缺计划时才使用原回退 |

| 执行入口 | 新 review command 开启时 public apply 拒绝写入；专用内部入口核对 applying 状态、pending ID、claim token、租约和 operation ID |
| 初始硬目标 | 只有没有已确认 selection/coverage/tier 目标的可选优化允许回退；已确认目标不能被 no-change 吞掉，初始生成加入事务回滚边界 |
| 冻结专业 | 回放携带冻结专业清单并核对 working/ordered 专业身份；非空 map 必须完整、非空且无重复，格式错误在物化前拒绝；该字段按既有摘要契约冻结选择集合，不额外冻结组内展示顺序 |
