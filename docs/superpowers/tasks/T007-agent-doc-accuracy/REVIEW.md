**追查 `volunteer_tool.py` 的方式是对的。** 三层：磁盘 `ls`、`git log --all -- '*volunteer_tool.py'`、全盘 `find`。三层全空，才能下"这个文件从来没存在过"的结论。只跑第一层只能证明"现在没有"，会把它误判成"被删掉的悬空引用"——这正是我上一轮犯过的错，当时我把它记成"疑似悬空文件"，实际是文档里凭空写出来的。三层追查把这个可能性排除了。

**超范围的两处补充都有理由，且都成立：**

- 小节标题从"Tools（意向提取工具）"改为"Tools（`app/tools/`）"。原副标题只覆盖 4 个模块中的 3 个，新列表含查询、方案校验等非意向抽取模块，旧标题会变成新的错误描述。改标题是必须的，不是扩范围。
